# Operating Systems Lab

Operating Systems coursework covering Linux shell commands, process exercises, virtual-machine setup and compiler installation, with original lab evidence.

[![Verify](https://github.com/fizaamjd/OS-LAB-tasks/actions/workflows/verify.yml/badge.svg)](https://github.com/fizaamjd/OS-LAB-tasks/actions/workflows/verify.yml)

## Overview

An educational archive of Markdown lab submissions, screenshots and a historical setup manual. These materials reflect the 2024 teaching environment; setup examples are not a current production hardening guide.

## Getting started

```sh
git clone https://github.com/fizaamjd/OS-LAB-tasks.git
cd OS-LAB-tasks
python3 scripts/check-docs.py
```
